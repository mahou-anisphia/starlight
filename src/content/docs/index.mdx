## What is this

This is my home page of the all-in-one document, where I write up about concept, and my journey, in tech.

From a starry-eyed CS student, with all sort of "all talk, no action" typical, to learning engineerning concept, and end up as security architect _(at the time I'm writing this)_.

The document will be written in an incremental way of reading, which, you'll be reading from the simplest term _(i.e. what even an application???)_ before the more advanced _(i.e. how to build one, what patterns?)_, and written in my own view about the field.

There will be 2 opening you could try on, as I designed by my experience as engineer (before) and security architect (as the time I write this) with 2 different starting point. Of course they will be referencing each other; i.e. a Security architect also need to know what is an application that "lives" in the internet, right? so, expect it to happen, and enjoy my work!
